# AI Tutor & Exam Practice System

A 10-member course project building an autonomous AI tutoring and exam practice system for Class 10 & 12 students.

## Overview

| Capability | Description |
|---|---|
| Doubt resolution | Answer student queries on curriculum topics |
| Mock exams | Generate, administer, and evaluate practice tests |

## Project Status

Phase: **0 — Initial scaffold / SDD setup** (in progress)
