## Agent Usage Policy

- All AI-assisted output must be reviewed and validated by a human before merging.
- Token usage must be logged in [TOKEN_USAGE.md](TOKEN_USAGE.md) after every session.
- Full agent session transcripts must be exported to `exports/`.
- Prompt logs must be saved to `agent_usage/`.
- No AI-generated code is merged without a linked spec in `specs/`.
